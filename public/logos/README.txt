PARTNER LOGOS
=============
Drop the official logo files here with these exact filenames. SVG preferred
(scales cleanly); .png works too, but then update the `logo` paths in
src/lib/content.ts to match the extension.

Until a file exists, that partner falls back to its name as a wordmark, so
the section never shows a broken image. Add them one at a time if you like.

FAST ALTERNATIVE
----------------
brandfetch.com has most of these as ready SVG/PNG downloads in one place -
e.g. brandfetch.com/rightmove.com, brandfetch.com/zoopla.co.uk. Handy for a
demo; for anything public-facing, prefer the company's own press kit so you
get the current approved mark and its usage terms.

NOTE ON USAGE
-------------
Showing these under a "Trusted Partners" heading reads as a claim that these
companies are partners. If they aren't signed partners yet, consider wording
like "Works with" or "Services we connect you with". This matters more for
the redress and deposit schemes (TPO, TDS), where implied membership is a
regulated claim.
